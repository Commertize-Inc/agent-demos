# Security policy

Please report suspected vulnerabilities privately by email to **support@commertize.com** with the subject line "Security report: agent-demos". Do not open a public issue for a security problem.

If you find a secret, key or seed phrase committed in any demo, report it the same way so it can be removed and the demo's builder notified.

Demos in this repository are written by their builders. Commertize reviews them before merging but does not maintain or warrant them; report problems in Commertize's own packages to the same address.

This policy creates no contractual obligation and offers no bounty.
